## Что внутри

* EDA телеметрии: заполненность каналов, значения на границах шкалы 0–1,
  интервалы между лабораторными замерами, корреляция каналов с целевой
  переменной при разных сдвигах.
* Подготовка данных: отбрасывание четырёх пустых каналов, закрытие
  пропусков последним известным значением не глубже 15 минут, признаки на
  минутной сетке — лаги 5/15/60, rolling-статистики на 15/60/240 минут,
  разности, темпы изменения, кодировка времени суток.
* Синхронизация редких замеров с телеметрией через `merge_asof`: задержка
  анализа выбирается перебором, дополнительно используются последний
  известный замер, время с него и дрейф каналов относительно него.
* Модели: Ridge (`RidgeCV` + `TimeSeriesSplit`), ExtraTrees,
  HistGradientBoosting; сравнение с константой и «последним замером»;
  абляция по наборам признаков и варианту с PCA; ARIMA как одномерный
  ориентир с AIC/BIC.
* Оценка на временном hold-out без перемешивания: MAE, RMSE, MAPE, WAPE,
  точность направления; диагностика остатков (Shapiro-Wilk, Ljung-Box,
  Breusch-Pagan) и permutation importance.

Итог: ансамблевые модели на поправке к последнему замеру дают MAE 0.051 на
`test_small` против 0.060 у базовой линии «последний замер». Основная часть
точности приходит из истории лабораторных замеров, телеметрия добавляет
около 0.003 MAE.
